🌸 Jinx für Debian und Ubuntu

Das apt-Repository für Jinx – Discord-Bots in einfachen Worten. Paket dotjnx, ab Debian 8 und Ubuntu 16.04, für amd64, arm64, armhf (Raspberry Pi), armel und i386.

Installieren

curl -fsSL https://jinxmrcl.github.io/dotjnx-apt/install.sh | sudo sh

Das fügt die Paketquelle einmal hinzu und installiert jinx. Neue Versionen kommen danach ganz normal mit

sudo apt update && sudo apt upgrade

Von Hand

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://jinxmrcl.github.io/dotjnx-apt/dotjnx.gpg | sudo tee /etc/apt/keyrings/dotjnx.gpg > /dev/null
echo "deb [signed-by=/etc/apt/keyrings/dotjnx.gpg] https://jinxmrcl.github.io/dotjnx-apt stable main" | sudo tee /etc/apt/sources.list.d/dotjnx.list
sudo apt update
sudo apt install dotjnx

Fingerabdruck des Signaturschlüssels: 9712 1206 6447 89EA 14DC D0FC E9A7 EDF3 9AA0 1C7B

Debian 8 und 9 und Ubuntu 16.04 brauchen noch ein paar Handgriffe mehr (apt-transport-https, bei den ältesten der Schlüssel in /etc/apt/trusted.gpg.d) – install.sh erledigt das von selbst.

Entfernen

curl -fsSL https://jinxmrcl.github.io/dotjnx-apt/install.sh | sudo sh -s -- --entfernen

English

The apt repository of Jinx, the language for Discord bots. Install it once with

curl -fsSL https://jinxmrcl.github.io/dotjnx-apt/install.sh | sudo sh

and get every new version with sudo apt update && sudo apt upgrade. It works from Debian 8 and Ubuntu 16.04 on. Remove it with curl -fsSL https://jinxmrcl.github.io/dotjnx-apt/install.sh | sudo sh -s -- --remove.
